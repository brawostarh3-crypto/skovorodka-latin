# База словаря

Исходные данные находятся в lexicon.json. После правок выполните
`node database/build.mjs` из папки сайта на Node.js 24 или новее.
Скрипт проверяет поля, уникальность словарных форм и ссылки на темы и источники.
Он пересобирает lexicon.sqlite и локальный браузерный снимок assets/lexicon.js.
Сайт читает снимок напрямую и работает без API и без доступа к сети.

Таблица terms хранит формы, перевод, род, учебную группу и тему.
Практическая основа рассчитывается из родительного падежа единственного числа.
Gen. pl. заполнен в статьях, где форма сверена с указанным пособием.
Таблицы topics и sources содержат темы и библиографические сведения.
Если источник не проставлен, статья перенесена из прежнего словника без индивидуальной привязки к изданию.

А и Б — учебные подгруппы смешанного типа, как в исходном конспекте.
Словарь охватывает существительные III склонения в рамках этого практикума.
